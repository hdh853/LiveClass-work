# 실행 방법

## 사전 요구사항

- **Java 17** 이상 설치
- 별도 DB 설치 불필요 (H2 인메모리 DB 사용)

---

## 로컬 실행

### 1. 빌드

```bash
# Windows
.\gradlew.bat build

# macOS / Linux
./gradlew build
```

### 2. 서버 실행

```bash
# Windows
.\gradlew.bat bootRun

# macOS / Linux
./gradlew bootRun
```

### 3. 실행 확인

서버가 정상 기동되면 아래 메시지가 출력됩니다:

```
Started EnrollmentApplication in X seconds
```

- **API 서버**: `http://localhost:8080`
- **H2 콘솔**: `http://localhost:8080/h2-console`
  - JDBC URL: `jdbc:h2:mem:enrollmentdb`
  - User: `sa`
  - Password: (빈칸)

---

## Docker 실행 (선택사항)

```dockerfile
FROM eclipse-temurin:17-jdk-alpine
WORKDIR /app
COPY build/libs/enrollment-system-0.0.1-SNAPSHOT.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "app.jar"]
```

```bash
# 1. 빌드
./gradlew build

# 2. Docker 이미지 빌드
docker build -t enrollment-system .

# 3. 컨테이너 실행
docker run -p 8080:8080 enrollment-system
```

---

## 설정 변경

`src/main/resources/application.yml`에서 주요 설정을 변경할 수 있습니다:

| 설정 | 기본값 | 설명 |
|------|--------|------|
| `server.port` | 8080 | 서버 포트 |
| `enrollment.cancel.allowed-days` | 7 | 결제 확정 후 취소 가능 일수 |
| `spring.jpa.hibernate.ddl-auto` | create-drop | DDL 전략 |

## 테스트 실행

```bash
# 전체 테스트
./gradlew test

# 특정 테스트 클래스
./gradlew test --tests "com.example.enrollment.enrollment.service.EnrollmentServiceTest"
```
